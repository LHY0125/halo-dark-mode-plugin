# 图片识别（视觉模型）

## 何时使用
用户发送图片/需要识别图片内容时自动触发。

## 调用方式（脚本位置固定，无需每次询问用户）
node scripts/vision.mjs <图片路径> "<要识别的内容/问题>"

## 图片路径获取
1. 消息里 [Image: source: <路径>] 给出的路径
2. Claude 的 image-cache 目录（最近接收的图片）
3. 用户明确给出的路径
4. 询问用户
